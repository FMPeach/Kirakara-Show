# 兼容性说明

## 当前支持

Kirakara Show 当前主要面向 Windows 10/11 x64：

| 功能 | 当前状态 |
|---|---|
| KRL / LRC 解析 | 可用 |
| Direct2D 歌词渲染 | 可用 |
| 视频与字幕合成 | 可用 |
| 实体第二屏 | 可用 |
| Flutter GPU 预览 | 可用，需要 Kirakara-App 对应接入 |
| H.264/AAC Cast | 可用，具体编码能力取决于系统与显卡驱动 |
| 非 Windows 平台 | 尚未支持完整构建与播放 |

## 建议测试的媒体

接入新设备或准备发布时，建议至少测试：

- 1080p60 和 1080p30；
- 4K 视频缩放到 1080p；
- 720p、480p 或 360p 视频放大显示；
- 有标题、无标题、双注音和多角色歌词；
- 播放、暂停、重唱、手动切歌与自然切歌；
- 原唱/伴奏切换与升降 Key；
- 本机第二屏和 Cast 各运行一遍。

## Windows 显示缩放

实体第二屏使用物理像素。主控屏和第二屏缩放比例不同时，应确认 Stage 完整覆盖目标显示器，
画面没有只显示一角或出现错误偏移。

Flutter 预览和 Show 最好使用同一块 GPU。混合显卡机器上如果预览无画面，应先检查 App 是否已
把正确的 D3D11 device 传给 Show。

## 低功耗设备

轻薄本或低功耗核显在高温降频后，可能无法持续承担 1080p60 解码、字幕合成、Flutter 界面和
Cast 编码。测试时不要只看总 GPU 占用，也要观察频率、温度和各 GPU engine 的使用情况。

Windows 11 24H2/25H2 在部分 Intel Xe-LP 设备上的调度与功耗表现仍需要更多实机验证。

## 已知限制

- 当前完整实现只支持 Windows。
- QR 与报幕 Overlay 的接口已经存在，正式绘制仍在开发中。
- Flutter 预览的流畅度会受 Flutter 界面自身重绘影响。
- 不同显卡和驱动提供的硬件 H.264 编码能力可能不同。
- 自动测试无法代替电视端观感、混合 DPI 和长时间热降频测试。

## 报告问题

提交问题时，最好一并提供：

- Windows 版本；
- CPU、GPU 和显卡驱动版本；
- 视频分辨率、帧率和音视频来源；
- 使用实体第二屏还是 Cast；
- 是否连接电源、是否已经发生热降频；
- 可复现的操作步骤和相关日志。
